# Arduino入門講座 第2回「自分でつないだLEDを、ボタンと光センサーで動かそう」教材

Arduino UNO R4 WiFi 用のスケッチです。ZIPをダウンロードしたら、必ず展開してから使います。
（第1回と同じ手順：教材ページの「Code」→「Download ZIP」→ すべて展開）

## ピン割り当て

| 用途 | ピン |
|---|---|
| 赤LED | D8 |
| 黄LED | D9 |
| 緑LED | D10 |
| ボタン入力 | D2（INPUT_PULLUP） |
| 光センサーの測定点 | A0 |

- 各LED：出力ピン → 1kΩ抵抗 → LEDのアノード（長い脚）→ カソード（短い脚）→ GND
- ボタン：D2 と GND の間（ななめの脚を使う）
- 光センサー：5V → 光センサー（フォトレジスタ）→ 測定点（A0）→ 10kΩ抵抗 → GND
  この配線では、明るいと数値が大きく、暗いと数値が小さくなります。

## スケッチ一覧

| フォルダー | 内容 | 時間 |
|---|---|---|
| `dai2_1_led_on` | 外付けの赤LEDを1個つける | 1時間目 |
| `dai2_2_led_blink` | 外付けの赤LEDを点滅させる | 1時間目 |
| `dai2_3_led_check` | 3色のLEDを1個ずつつけて配線を確認する | 2時間目 |
| `dai2_4_signal_hinagata` | ミニ信号機のひな形（黄・赤のブロックを作る） | 2時間目 |
| `dai2_4_signal_kansei` | ミニ信号機の完成例（緑→黄→赤） | 2時間目 |
| `dai2_5_button_led` | ボタンを押している間だけ赤LEDをつける | 2時間目 |
| `dai2_6_light_monitor` | 光センサーの数値をシリアルモニタに表示する | 3時間目 |
| `dai2_7_light_led` | 暗くなると赤LEDがつく | 3時間目 |
| `dai2_8_light_kaizo_hinagata` | 光センサーの改造ワーク用ひな形 | 3時間目 |
| `dai2_8_light_kaizo_kaitou` | 改造ワークの解答例（講師用） | 3時間目 |

- シリアルモニタの通信速度は 9600 baud にします。
- 数値は、明るさを比べるための値です（照度「ルクス」ではありません）。教室の明るさや部品によって変わります。
- 配線を変えるときは、必ずUSBケーブルを外してから行います。
